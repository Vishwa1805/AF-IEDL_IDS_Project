# IEDL-IDS CNN Encoder + MLP Baseline

This is the first trainable model stage for the ToN_IoT image arrays generated by `prepare_iedl_images.py`.

## Paper-aligned components

- Input: RGB images with shape `21 x 21 x 3`.
- Encoder: `Conv2d(3,64,3,padding=1) -> ReLU -> MaxPool2d(2) -> Conv2d(64,32,3,padding=1) -> ReLU -> MaxPool2d(2)`.
- Spatial output: `32 x 5 x 5`; flatten size: `800`.
- A fully connected latent layer is used before the classifier.
- Training defaults follow the paper's image-based IEDL-IDS settings: Adam, learning rate `0.001`, batch size `64`, `50` epochs, dropout `0.5`.

## Explicit implementation choices

The paper does not state the exact latent width or fully specify the MLP classifier's output dimensions. This implementation uses a latent width of 16 (less than `n=21`), one 256-unit ReLU hidden layer, dropout 0.5, and a 9-logit output layer. These choices must be disclosed in the project report.

This script returns logits and uses `CrossEntropyLoss`; do not apply softmax before the loss.

## Install

Use a standard CPython Windows installation that has a compatible PyTorch wheel. In particular, avoid assuming that a Python distribution bundled with MSYS2 will be supported by the official PyTorch Windows wheels.

```powershell
py -m pip install -r requirements.txt
py -c "import torch; print(torch.__version__); print('CUDA:', torch.cuda.is_available())"
```

## Run

```powershell
py train_iedl.py --data-dir "D:\path\to\IEDL_IDS_Project\iedl_images" --out-dir "D:\path\to\IEDL_IDS_Project\baseline_results"
```

The training script loads only the three generated NPZ files. It does not read the original 23 CSV shards or the sampled CSV.

## Outputs

- `best_model.pt`
- `training_history.csv`
- `test_metrics.json`
- `classification_report.json`
- `confusion_matrix.csv`

The best checkpoint is selected using validation macro-F1 because the nine-class image set is highly imbalanced. Test data is evaluated only after checkpoint selection.

## Input schema

The NPZ files must contain keys `X` and `y`. `X` is expected as `uint8` NHWC with shape `(N,21,21,3)`, and `y` as integer class IDs 0 through 8.
